# QUACK Community

## Welcome

Welcome to the QUACK community! We're building an open-source AI Operating System, and we'd love your help.

## Getting Started

1. Read the [README.md](./README.md)
2. Check the [CONTRIBUTING.md](./CONTRIBUTING.md) guide
3. Browse [open issues](https://github.com/mahatosumit/QUACK/issues)
4. Join discussions on GitHub Discussions

## Communication Channels

- **GitHub Issues:** Bug reports and feature requests
- **GitHub Discussions:** Q&A, ideas, community conversations
- **Discord (planned):** Real-time chat and support
- **Twitter/X (planned):** Announcements and updates

## How to Contribute

We welcome contributions of all kinds:

- **Code:** Bug fixes, features, performance improvements
- **Documentation:** Guides, tutorials, API docs, ADRs
- **Testing:** Test cases, integration tests, bug reports
- **Design:** UI/UX improvements, diagrams, visual assets
- **Community:** Answering questions, reviewing PRs, mentoring

See [CONTRIBUTING.md](./CONTRIBUTING.md) for details.

## Project Values

- **Quality over quantity:** Clean, tested, documented code
- **Respectful collaboration:** Follow our Code of Conduct
- **Transparency:** Open decisions, open discussions
- **Incremental improvement:** Small, focused, reviewable changes

## Recognition

Contributors are recognized in:
- Release notes for significant contributions
- MAINTAINERS.md for sustained contributors
- GitHub's built-in contributor graph

## Code of Conduct

All community participants must follow our [Code of Conduct](./CODE_OF_CONDUCT.md).
