## Maintainer Responsibilities

1. Review and merge pull requests
2. Triage and respond to issues
3. Maintain project roadmap and vision
4. Manage releases and versioning
5. Review and approve architecture decisions
6. Mentor contributors and committers
7. Ensure code quality and test coverage
8. Maintain documentation quality

## Becoming a Maintainer

1. Demonstrate sustained contribution over 6+ months
2. Show deep understanding of the codebase
3. Participate actively in code reviews
4. Contribute to architecture discussions
5. Be nominated by an existing maintainer
6. Approved by consensus of current maintainers
