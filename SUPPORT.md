# Support

## Getting Help
If you need help using QUACK OS, please refer to the following resources:

1. **Documentation**: Ensure you have read the `README.md` and the SDK documentation in the `docs/` directory.
2. **GitHub Discussions**: The best place to ask questions, share workflows, and learn from other developers.
3. **Issues**: If you believe you have found a bug, please open an Issue using the provided `bug_report.md` template. Feature requests should use the `feature_request.md` template.

## Commercial Support
QUACK OS is an open-source project managed by the core maintainers. Currently, there is no official commercial support or SLA provided. Use it at your own risk in production environments.

## Reporting Security Vulnerabilities
Please do NOT open a public issue for security vulnerabilities. Review our [SECURITY.md](SECURITY.md) file for instructions on how to securely disclose vulnerabilities to the maintainers.
