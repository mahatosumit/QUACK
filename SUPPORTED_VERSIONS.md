# Supported Versions

## Version Support Matrix

| Version | Status | Security Fixes | Bug Fixes | New Features |
|---------|--------|---------------|-----------|--------------|
| 1.0.x   | ✅ Active | ✅ | ✅ | ✅ |
| < 1.0   | ❌ EOL | ❌ | ❌ | ❌ |

## Lifecycle

- **Active:** Receives all updates including security patches, bug fixes, and features
- **Maintenance:** Receives only critical security and bug fixes
- **EOL (End of Life):** No longer receives any updates

## Schedule

- Each major version is actively supported for a minimum of 12 months
- After the active period, versions enter a 6-month maintenance window
- After the maintenance window, versions reach EOL

## Upgrade Recommendations

- Always use the latest stable release
- Upgrade to new major versions within the active support window
- Test upgrades in a staging environment before production
