# QUACK Benchmark Report

No current reproducible performance baseline or comparative result is certified
by this document. Earlier tables mixed historic test-suite timings, estimates,
and simulated subsystem results without sufficient run provenance. Those values
have been withdrawn as release evidence.

Current source checks and dated implementation reports describe only the revision
and environment they actually tested. See the
[production readiness report](production/PRODUCTION_READINESS_REPORT.md) for
known limits and [benchmarking strategy](BENCHMARKING_STRATEGY.md) for the proposed
measurement process.

The scheduled coverage workflow produces test coverage, not a model-quality or
runtime-performance benchmark. Phase 1 does not add benchmark execution or claim
that QUACK outperforms another runtime.
