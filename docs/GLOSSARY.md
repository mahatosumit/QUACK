# QUACK Glossary

| Term | Definition |
|------|------------|
| ADR | Architecture Decision Record — documents a significant design decision |
| Agent | A specialized worker with a defined role, capabilities, and permissions |
| AIRM | AI Runtime Manager — central AI execution orchestrator |
| Audit Log | Append-only record of all runtime events |
| Capability | A measurable AI function (reasoning, coding, vision, etc.) |
| COS | Cognitive Operating System — strategic intelligence layer |
| DAG | Directed Acyclic Graph — workflow representation used by the engine |
| DNPL | Distributed Native Platform Layer — OS/hardware abstraction |
| Event Bus | Central typed pub/sub system for all state changes |
| Executive Brain | Top-level orchestration layer |
| Factory | A function (create*()) that constructs a fully-wired subsystem |
| Intelligence Router | Capability-based AI model selector |
| IsoTimestamp | Branded ISO-8601 timestamp string |
| Knowledge Graph | Entity-relationship store with typed edges |
| LSP | Language Server Protocol — code intelligence protocol |
| Marketplace | Plugin/skill/model package catalog |
| Memory | Durable key-value store with TTL and scope |
| Pipeline | Multi-step AI workflow (e.g., review → analyze → report) |
| Plugin | Extensible module with lifecycle management |
| Provider | AI model service adapter (OpenAI, Ollama, etc.) |
| Quantization | Model compression technique (GGUF, AWQ, GPTQ, etc.) |
| Sandbox | Isolated execution environment with policy enforcement |
| SEA | Software Engineering Agent — code analysis and editing |
| Skill | Reusable capability with manifest and execution |
| UCP | Universal Computer Use Platform — GUI automation |
| VRAM | Video RAM — GPU memory for model loading |
| Workspace | Project context with panel layouts and recent files |
