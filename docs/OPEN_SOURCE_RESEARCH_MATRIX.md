# Open-source research matrix

QUACK retains ownership of planning, runtime, verification, memory contracts, approvals, capability brokering, and the harness.

| Repository | Decision | QUACK use |
|---|---|---|
| ruvnet/ruflo | ADAPT_PATTERN_ONLY | Harness, swarm, and plugin patterns |
| Panniantong/Agent-Reach | ADOPT_AS_OPTIONAL_ADAPTER | Disabled, capability-gated research adapter |
| Shubhamsaboo/awesome-llm-apps | ADOPT_AS_RECIPE_INDEX | Metadata-only recipe source |
| BerriAI/litellm | ADOPT_AS_OPTIONAL_ADAPTER | Deployment gateway option, never core |
| vercel/ai | ADAPT_PATTERN_ONLY | Provider and streaming patterns |
| mem0ai/mem0 | ADOPT_AS_OPTIONAL_ADAPTER | Future memory adapter |
| getzep/graphiti | ADOPT_AS_OPTIONAL_ADAPTER | Future graph-memory adapter |
| microsoft/autogen | REFERENCE_ONLY | No runtime integration |
| crewAIInc/crewAI | ADAPT_PATTERN_ONLY | Workflow and review patterns |
| modelcontextprotocol/servers | ADOPT_AS_OPTIONAL_ADAPTER | Narrow tool-server interoperability |
| vllm-project/vllm | ADOPT_AS_OPTIONAL_ADAPTER | OpenAI-compatible local provider endpoint |

No external source code is copied into QUACK without a separate license and attribution review.
