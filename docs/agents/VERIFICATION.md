# Independent Verification

The executor is not sufficient to certify its own work. A company plan contains
exactly one designated verifier. Production tasks cannot be assigned to it.
Completion requires `VERIFYING`, an approved verifier record, and a durable
evidence reference linked to the company record.

Identity checking binds the verdict to the designated live instance ID. Company
tool and action entry points use opaque runtime-issued principals tied to the
mission, instance, grant, and lease. Model/provider and terminal egress paths do
not yet all enforce that principal, so system-wide identity separation remains
a release blocker.
