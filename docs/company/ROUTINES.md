# Routines

Routines are future mission triggers, not invisible always-on agents. A manual,
scheduled, event, or API trigger must create or update a tracked mission, which
then assembles a temporary company under the same budgets, grants, approvals,
evidence, and verification rules.

The current repository has in-memory time-management primitives, but no durable
routine-to-mission implementation. Therefore routines remain **NOT_IMPLEMENTED**
and must not appear as active or scheduled in production UI.
