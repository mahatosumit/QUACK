# Knowledge Fabric v1

The governing rule is: **knowledge persists; compute does not.** Raw sources
remain immutable where practical. Derived pages must name source references,
verification evidence, mission, and version. Contradictions and superseded
decisions are appended rather than silently overwritten.

The Company Runtime currently preserves evidence and knowledge references after
all worker instances and grants are released. It does not yet validate source
hashes, run knowledge lint, or enforce verifier-gated long-term promotion.
Local Markdown/project docs are the intended first provider; Obsidian and
Graphify remain optional adapters and are not Core dependencies.
