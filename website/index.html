QUACK AI Operating System

A production-ready, provider-independent AI Operating System with capability-based routing, multi-agent orchestration, distributed execution, and an intelligence runtime manager.

Features

AI Runtime Manager

Capability-based routing across 27 capabilities. Model registry, GPU scheduler, memory manager, quantization, and prompt caching.

Multi-Agent Organization

18 specialized agents with communication bus, voting, negotiation, lifecycle management, and organizational memory.

Distributed Runtime

Remote execution, container orchestration, capability negotiation, and cross-node distribution.

Executive Brain

Strategic planning, goal decomposition, task graphs, reflection, and self-improvement.

Universal Computer Use

GUI automation, browser control, vision-based interaction, macro recording, and session replay.

Software Engineering Agent

Code analysis, editing workflows, review system, test intelligence, refactoring, and repository understanding.

Plugin & Skill System

Plugin platform with lifecycle, updates, marketplace. Skill system with registry, validation, quarantine-first execution.

Desktop Platform

HTTP API server with 80+ endpoints, Electron shell, React GUI, IPC bridge, and Chrome DevTools protocol.

Getting Started

# once the first release is published to npm
npm install -g @quack/os

quack start "bootstrap the coding agent"
quack serve --port 3157
quack --help
import { createQuackSystem } from "@quack/os";

const system = createQuackSystem();
const result = await system.runtime.submitGoal("analyze the codebase");
console.log(result.data);
